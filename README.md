# NexusCraft Shoop

Loja demonstrativa com catálogo inicial, filtros de categorias e tela separada de finalização. Todos os preços de exemplo são de até R$ 10,00.

## Publicar no Render
- Build Command: `npm install`
- Start Command: `npm start`

Importante: Pix/cartão e entrega automática não estão integrados. Configure produtos, preços e benefícios reais antes de vender. Não coloque chaves secretas no GitHub.
